# Important IIoT Viva Questions

1. **What is IIoT?** The use of connected sensors, devices, and systems in industrial environments to monitor and control processes.
2. **Sensor vs actuator?** A sensor measures; an actuator performs an action.
3. **What is telemetry?** Measurement data collected and transmitted from a device.
4. **What is a threshold?** A limit used to trigger a state change or action.
5. **What is predictive maintenance?** Using equipment-condition information to anticipate maintenance needs.
6. **What is condition monitoring?** Observing operating parameters to assess equipment state.
7. **What is PWM?** Pulse-width modulation, commonly used to control average power to a load.
8. **What is a relay?** An electrically operated switch.
9. **What does active LOW mean?** A LOW logic level activates the input.
10. **Why is a motor driver needed?** Motors usually need more current than a microcontroller pin can provide.
11. **What does an LDR do?** Its resistance changes with light intensity.
12. **What is the limitation of MQ sensors?** They need warm-up/calibration and are not precise certified instruments by default.
13. **How does an ultrasonic sensor measure distance?** By timing the reflected sound pulse.
14. **What is sensor calibration?** Comparing sensor output against a reference and adjusting the measurement relationship.
15. **What is IoT cloud monitoring?** Sending device data to a remote service for storage, visualization, or analysis.
16. **What is energy?** Power accumulated over time.
17. **What is AES-GCM?** An authenticated encryption mode that provides confidentiality and integrity.
18. **What is a nonce?** A value intended to be used only once in a cryptographic operation.
19. **Is hashing the same as encryption?** No; a cryptographic hash is one-way, while encryption is designed to be reversible with a key.
20. **Does TCP encrypt data?** No. TCP provides reliable ordered byte-stream transport, not confidentiality.

## Last-minute practical checklist

- State the aim and identify each component.
- Explain the sensor's physical principle in one or two sentences.
- Trace the data path: sensor → controller → processing → output/dashboard.
- Know the role of each pin from your actual circuit diagram.
- Explain the condition that turns an LED, buzzer, relay, or motor on.
- Mention calibration, limitations, and safety.
- Use only the thresholds and pin assignments in your official lab record.
